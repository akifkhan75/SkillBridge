# Prolivo — User Flows

## Customer flow — standard job

Home
→ “What do you need help with?”
→ text/voice/photo/video
→ AI analysis
→ safety check
→ customer confirms job brief
→ choose ASAP / schedule
→ see matched professionals
→ compare profile / price / ETA
→ confirm
→ payment authorization
→ professional accepts
→ live status
→ arrival
→ job starts
→ work / evidence
→ extra work approval if needed
→ completion
→ customer confirms
→ payment capture/release
→ review
→ save/rebook

## Customer flow — AI visual diagnosis

Capture photo/video
→ AI identifies likely category
→ AI states uncertainty
→ asks clarifying questions
→ recommends safe next action
→ recommends professional
→ customer confirms
→ booking

Never present a visual diagnosis as a guaranteed professional diagnosis.

## Customer flow — emergency

Emergency entry
→ classify emergency type
→ show immediate safety guidance
→ show local emergency contacts
→ offer call/action through supported device capability
→ optional trusted-contact notification
→ if suitable, offer nearby verified Prolivo professional for non-life-threatening property emergency
→ incident tracking

Do not route life-threatening situations to ordinary marketplace workers as a replacement for emergency services.

## Professional onboarding

Phone/email
→ identity
→ selfie/liveness if required
→ legal name
→ address/service area
→ trade categories
→ experience
→ credentials
→ insurance
→ equipment
→ pricing
→ availability
→ payout account
→ agreements
→ verification review
→ approved/limited/rejected
→ go online

## Professional job flow

Go online
→ eligible request
→ preview
→ accept/decline
→ customer notified
→ navigation
→ arrive
→ start job
→ checklist
→ photos/notes
→ quote/change order if required
→ customer approval
→ complete
→ customer confirmation
→ payout

## Quote-required job

Request
→ AI intake
→ match
→ provider inspection/remote assessment
→ quote
→ customer compares/accepts
→ payment authorization
→ scheduled work

## Dispute flow

Customer/provider opens dispute
→ select reason
→ evidence upload
→ payment hold where applicable
→ support review
→ request additional evidence
→ resolution
→ refund/partial payment/chargeback support/appeal
→ audit record

## Cancellation flow

Before acceptance:
- customer can cancel freely.

After provider acceptance:
- cancellation rules depend on time, provider travel and job type.

After arrival:
- cancellation becomes a support/fee workflow.

Emergency:
- never block safety access because of payment state.

## Rebooking

Completed job
→ “Book again”
→ same provider availability
→ previous scope shown
→ customer edits details
→ confirm
